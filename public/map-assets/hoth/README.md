# Hoth map asset bundle

Selected top-down snow and mountain sprites from **Kenney Foliage Pack 1.0** and rock and
structure sprites from **Kenney Sci-Fi RTS 1.0**.

- Foliage source: https://kenney.nl/assets/foliage-pack
- Sci-Fi source: https://kenney.nl/assets/sci-fi-rts
- Author: Kenney Vleugels (Kenney.nl)
- License: Creative Commons Zero (CC0 1.0)
- License URL: https://creativecommons.org/publicdomain/zero/1.0/
- Retrieved: 2026-08-10

The source packs permit use in personal and commercial projects. Attribution is not required,
but is retained here as a courtesy and to preserve asset provenance.

## Selected files

- `foliagePack_054–055.png` -> light ice-rock cover
- `foliagePack_060.png`, `foliagePack_062.png` -> heavy snow ridges
- `scifiEnvironment_12–13.png` -> rough crystalline ice
- `scifiStructure_05.png`, `scifiStructure_10.png` -> ice-base buildings
- `scifiStructure_01.png`, `scifiStructure_07.png`, `scifiStructure_11.png`,
  `scifiStructure_13.png`, `scifiStructure_16.png` -> scenario objectives and fortifications

Files were renamed for stable, semantic URLs. Original Retina PNG dimensions and artwork are
unchanged.
