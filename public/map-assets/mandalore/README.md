# Mandalore city map assets

Original top-down vector battlefield pack created for LEGO Star Wars Battles.

- Style: angular durasteel city sectors, domes, plazas and turquoise light strips
- Format: transparent 128 × 128 SVG
- License: CC0 1.0
- Created: 2026-08-11

The silhouettes are original project artwork and do not reproduce emblems or models from external asset packs.
