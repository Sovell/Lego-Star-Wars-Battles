# Ryloth generated art pack

Project-local tactical terrain assets generated with the built-in OpenAI image generation tool on 2026-08-14, then downscaled to transparent 256×256 PNG files.

Visual direction: warm layered red sandstone, dry scrub, turquoise Twi'lek-inspired accents, simplified toy-like isometric geometry. No external source images were used.

Files cover light and heavy cover, difficult terrain, buildings, impassable terrain and high ground. Some gameplay categories intentionally reuse the closest matching sprite until dedicated object art is added.
