# Ryloth generated art pack

Project-local tactical terrain assets generated with the built-in OpenAI image generation tool on 2026-08-14 and 2026-08-15, then downscaled to 256×256 PNG files.

Visual direction: warm layered red sandstone, dry scrub, turquoise Twi'lek-inspired accents, simplified toy-like isometric geometry. No external source images were used.

Files cover open ground, light and heavy cover, difficult terrain, buildings, impassable terrain and high ground. The open-ground texture is opaque; object sprites use transparency. Some gameplay categories intentionally reuse the closest matching sprite until dedicated object art is added.

## Construction-brick refresh (`brick-v2`)

The six `*-brick-v2.png` files form a 512×512 pilot refresh created on 2026-08-15. They reinterpret the original Ryloth silhouettes as original, generic interlocking construction-brick builds with visible studs and modular plates. The designs do not reproduce an official kit and contain no logos, trademarks or brand markings. The earlier `*-a.png` files remain available as preserved source variants.
