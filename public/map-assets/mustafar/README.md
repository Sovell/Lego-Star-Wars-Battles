# Mustafar map asset bundle

Selected top-down volcanic rocks and industrial structure sprites from
**Kenney Sci-Fi RTS 1.0**.

- Source: https://kenney.nl/assets/sci-fi-rts
- Author: Kenney Vleugels (Kenney.nl)
- License: Creative Commons Zero (CC0 1.0)
- License URL: https://creativecommons.org/publicdomain/zero/1.0/
- Retrieved: 2026-08-10

The source pack permits use in personal and commercial projects. Attribution is not required,
but is retained here as a courtesy and to preserve asset provenance.

## Selected files

- `scifiEnvironment_02–05.png` -> basalt cover
- `scifiEnvironment_06–07.png` -> mineral-rich difficult terrain
- `scifiStructure_04.png`, `scifiStructure_08.png` -> foundry buildings
- `scifiStructure_01.png`, `scifiStructure_03.png`, `scifiStructure_07.png`,
  `scifiStructure_12.png`, `scifiStructure_16.png` -> scenario objectives and fortifications

Files were renamed for stable, semantic URLs. Original Retina PNG dimensions and artwork are
unchanged.
