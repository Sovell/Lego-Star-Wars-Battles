# Republic research station generated art pack

Project-local tactical terrain assets generated with the built-in OpenAI image generation tool on 2026-08-14 and 2026-08-15, then downscaled to 256×256 PNG files.

Visual direction: white and graphite Republic laboratory modules with cyan illumination and restrained red warning accents, simplified toy-like isometric geometry. No external source images were used.

Files cover open ground, light and heavy cover, damaged terrain, laboratory buildings and raised research platforms. The open-ground texture is opaque; object sprites use transparency. Some gameplay categories intentionally reuse the closest matching sprite until dedicated object art is added.

## Construction-brick refresh (`brick-v2`)

The six 512×512 `*-brick-v2.png` files were generated on 2026-08-15 as original generic construction-brick models. Their visible studs, modular plates and buildable silhouettes match the Ryloth pilot without reproducing any official kit or using logos, trademarks or brand markings. Runtime map definitions use these new files while preserving the earlier `*-a.png` variants.
